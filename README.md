# Monte Carlo: площадь пересечения трех кругов

Приближенное вычисление площади пересечения трех окружностей методом Монте-Карло и анализ точности оценки.

## Постановка задачи

Реализован алгоритм Монте-Карло на C++ для приближенного вычисления площади фигуры, образованной пересечением трех кругов с заданными центрами и радиусами.

Экспериментально исследуется точность оценки площади в зависимости от:

- масштаба прямоугольной области для генерации точек:
  - **широкая** область (прямоугольник, в котором находятся все 3 круга целиком);
  - **узкая** область (прямоугольник, более плотно охватывающий пересечение);
- количества случайных точек `N` (от 100 до 100000 с шагом 500).

Для каждого `N` оценивается:

- приближённая площадь `S̃` для широкой и узкой области;
- относительное отклонение `|S̃ − S_exact| / S_exact` от точного значения площади
  \(`S_exact = π/4 + 1.25·arcsin(0.8) − 1`\).

## Структура репозитория

- `code/`
  - `main.cpp` — C++-реализация метода Монте-Карло, генерирующая данные по всем `N`.
- `data/`
  - `data.csv` — результаты экспериментов (`N`, `S_wide`, `rel_err_wide`, `S_narrow`, `rel_err_narrow`).
- `plots/`
  - `plot1.png` — график 1-го типа: зависимость оценки площади `S̃` от `N` (широкая и узкая области).
  - `plot2.png` — график 2-го типа: зависимость относительной ошибки от `N`.
  - `plots.ipynb` - построение графиков.

## Выводы по графикам

### Графики первого типа (S(N))

- При малых `N` оценки площади заметно сильно прыгают вокруг точного значения, но уже видна тенденция сходимости.
- При увеличении `N` до десятков тысяч приближённая площадь стабилизируется около `S_exact`, как и ожидается для метода Монте-Карло.
- Для **узкой** прямоугольной области значения `S̃` колеблются ближе к точному значению и менее шумные по сравнению с широкой областью при том же `N`.

### Графики второго типа (относительная ошибка)

- Относительная ошибка убывает при росте `N`: удвоение точности требует порядка четырёхкратного увеличения числа точек.
- Для **широкой** области относительная ошибка для тех же `N` заметно выше, так как доля попаданий в целевую область мала и дисперсия оценки больше.
- Для **узкой** области относительная ошибка значительно меньше: прямоугольник плотнее охватывает пересечение кругов, доля попаданий выше, дисперсия ниже.
- Таким образом, выбор компактной области интегрирования при прочих равных существенно улучшает точность метода Монте-Карло без изменения числа точек.
